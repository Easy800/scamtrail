# 编辑与发布政策

Review and Publish are **separate actions** (ST-DEV-001 §4, §13.3, TM-2 Publish 人工).

## Allowed public wording

- “两个独立 Case 中观察到相同 Telegram 用户名。”
- “该身份或图片被观察到用于诈骗活动，不代表已确认背后的现实人物身份。”

## Forbidden automatic wording

- “两个案件由同一个现实人物或同一个诈骗集团操控。”
- “诈骗集团已消失。”
- Marking a legal name as a scammer from an avatar match.

## Rules

1. Intake stays quarantined until structured.
2. Matchers create Candidates, not Public Relationships.
3. Public Claim text comes from a Decision record.
4. GitHub PRs are suggestions, not production facts.
5. Trail copy (首次发现 / 最近发现 / 关联痕迹) must not say “convicted” or “this person is a fraudster.”
