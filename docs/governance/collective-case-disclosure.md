# Collective Case 披露政策

Thresholds create a **human review candidate**. They never send data to police (ST-DEV-001 §18, ADR-008, TM-4 警方无后台).

## Activation dimensions (config, not a single dollar cutoff)

Independent reporters in one jurisdiction; supported loss; still-active; shared infrastructure strength; payment-evidence ratio; repeated paths; vulnerable groups; consent types held; an operable recipient.

## Package (12 parts)

Executive Summary; method and limits; anonymous victim table for the jurisdiction; supported vs declared loss; path and roles; shared infrastructure; Evidence Manifest (id/hash/type/permission, originals off by default); consent matrix; redacted attachments only if granted; contact list only if further granted; known disputes; package version/hash/time.

## Recipient

Verify via an independent official channel. Require a case number or written intake basis. No delivery through unknown chat accounts. One-shot minimized package. No admin or Vault login.

State on every submit and Case page: 记录不等于向警方报案。
