# Contributing to 诈迹 · ScamTrail

GitHub is for code, schemas, taxonomy, translations, public-source *pointers*, and corrections to **already published** public fields.

GitHub is **not** an evidence inbox.

## Do not upload these to GitHub

- ID documents (身份证、护照、驾照)
- Chats or full message exports (聊天记录、邮件原文)
- Payment screenshots (付款截图、银行卡、账单)
- Victim names, phone numbers, email addresses, home addresses
- Unreleased real-person accusations

**禁止在 GitHub 上传身份证、聊天记录或付款截图。**  
Do not upload ID documents, chats, or payment screenshots to GitHub.

If you are a victim or witness, use the product submission form when it is live. Never open a GitHub Issue with original files.

## What we do accept

- Code, tests, accessibility, and documentation
- Taxonomy and translation
- Public-source URLs that are already public
- Schema validators and redaction helpers
- Corrections to published P0 fields, as *suggestions* — PRs do not become production facts

See `docs/governance/threat-model.md` (投稿隔离, Publish 人工).
